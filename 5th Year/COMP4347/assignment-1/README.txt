# How to start this application

1. If you have not installed Node.js already, please install it from here https://nodejs.org/en/download/. Once installed, please run this command in your terminal: “npm install http-server -g”
2. Navigate to this directory in your terminal.
3. Run the command “http-server” and open the project in your browser at 127.0.0.1:8080.
